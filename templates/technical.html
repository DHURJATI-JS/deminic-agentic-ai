{{ icon('target', 'w-5 h-5 text-accent-500') }}Vector routing instead of regex

Every decision the agent makes is answered by a nearest-neighbour search in PostgreSQL (pgvector) instead of hand-written regular expressions. Prototype phrases for each tool, memory category, profile question, summary trigger and injection pattern are embedded once into the intent_vectors table.

At request time the message vector is compared against those prototypes; similarity above a tuned threshold activates the intent. If no tool is close enough the router is skipped entirely, which keeps plain conversation fast. Regex is only used where an exact syntax must be matched (URLs, e-mail addresses, chat#N references, API-key formats).

  • Failed calls are retried with backoff; a provider that refuses connections is skipped for a short time by a circuit breaker.
  • If a provider dies mid-answer, the next provider restarts the answer and the UI resets the partial text.
  • Coding mode never uses Gemma: it uses a Qwen model on your gateway if served, then the Docker Qwen fallback, then online models.
  • The strict BEYOND MY LIMITS rule is in every local prompt; the phrase is detected while streaming (the first characters are held back) and triggers the escalation function.

{{ icon('brain', 'w-5 h-5 text-accent-500') }}Memory & chat history

chat_histories

One row per chat: a JSONB MutableList of {chatno, prompt, reply, ...} dicts plus the compacted-history text column.

memories + memory_vectors

Global memory per mode (personal, business, coding). Family contacts are memories too. Each entry has a vector for semantic recall.

Wiping memory

A protected background task: memories removed, tasks/reminders kept but marked stale and removed from the vector store.

  • Standing instructions. Rules like "stop reassuring me" or "reply in bullet points" are saved as category instruction and added to every reply in that mode, not only when they seem relevant.
  • Typo-proof save requests. "save thios to my global emmeory" is recognised by combining the message embedding with a character-trigram embedding. The remember tool is then put in front of the router.
  • No false claims. Each reply is checked sentence by sentence (vector similarity) for claims like "I've added that to your memory". If nothing was saved, Deminic performs the save, or corrects the reply.

{{ icon('lock', 'w-5 h-5 text-accent-500') }}Encryption at rest

Sensitive columns use transparent SQLAlchemy types backed by Fernet (AES-128-CBC + HMAC-SHA256). The database only ever stores enc:... tokens; the key lives in .env.

DataHow it is stored
Chat historiesprompt / reply / cards / location / attachments encrypted per message; compacted history, titles and main points encrypted
Health & financial memorykey, value and details encrypted; uniqueness via a keyed HMAC; the vector embeds only category + label, never the value
Statements, reminders, summaries, simulations, e-mailsamounts, counterparties, descriptions, bodies and results encrypted
PasswordsArgon2id (OWASP parameters) — never reversible
API keys, SMTP key, GitHub tokenFernet-encrypted, shown masked in settings
Login tokenonly its SHA-256 hash is stored (users.session_token_hash)

{{ icon('history', 'w-5 h-5 text-accent-500') }}Background tasks & restore points

Cancellable tasks

Replies, scans, Locust runs, clones, news digests, reminders. Cancels travel over Socket.IO with the exact request id and are only accepted from the owner. Reminders can be cancelled until 3 minutes before they are due.

Protected tasks (like a Windows restore point)

Memory deletion, global reset and multi-file code applies open a restore point first and record an undo step before every change. If they fail, are interrupted or the app closes, the undo log is replayed back to that timestamp — verified by killing the server mid-wipe.

{{ icon('briefcase', 'w-5 h-5 text-accent-500') }}The three modes

{{ icon('user', 'w-4 h-4') }}Personal

Tasks with location, a same-name processing queue, reminders, calendar with Google Calendar links and Meet hand-off, family profiles and e-mail, weather, travel guide, movies (YouTube or where to stream) and music, mind-map summary.

{{ icon('briefcase', 'w-4 h-4') }}Business

Clients remember the chat and reason they were added; removing a client removes its reminders. Credit/debit statements, cold sales e-mails in the sent inbox, a daily news digest with opportunities, what-if simulations and a business AI summary. The business name is a live {business_name} variable.

{{ icon('code', 'w-4 h-4') }}Coding

A per-chat project plus the unified workspace, an editor with syntax colours and auto-closing brackets, the vulnerability gate, a scanner, Locust stress tests and GitHub.

{{ icon('shield', 'w-5 h-5 text-accent-500') }}The coding gate

Nothing is written to disk until it passes. On every save (or AI change): new dependencies are extracted from manifests and import statements, unpinned ones are resolved to their latest version, and all of them are checked against OSV.dev. The content is also scanned by ClamAV and for leaked secrets. A vulnerable package blocks the write and the gate recommends the first fixed version or a safer alternative; multi-file changes roll back completely if any file is blocked.

{{ icon('sparkles', 'w-5 h-5 text-accent-500') }}Interface & immersive mode

  • Liquid-glass design system (Tailwind) with dark/light themes, one consistent icon set and smooth React-like transitions (View Transitions API with a CSS fallback).
  • Immersive / VR mode renders a realistic animated environment on a canvas behind the glass: a starry night with nebula, moon and shooting stars in dark mode; a time-of-day sky with sun, drifting clouds, hills and flocks of birds in light mode. Parallax follows your pointer or Quest controller; on a Meta Quest it switches on with a larger comfort layout.
  • Command palette (Ctrl+K) and an in-app terminal with Tab completion, history and AI-suggested commands (type ? plus what you want).
  • System status (the signal button next to the theme toggle) pings every component every 2 seconds: gateway and model loaded, coding model, Docker fallbacks, embeddings, PostgreSQL, Redis, ClamAV and the live socket. Each row shows its latency and a history graph. A real AI response test asks the local models to reply "pong" and times the first token.
  • A gradient navigation bar sweeps across the top of the page on every page change, chat switch and tab switch.
  • No browser storage: saved accounts, theme and UI state live in Redis.

{{ icon('rocket', 'w-5 h-5 text-accent-500') }}Deployment & LAN access

One-click: install.bat / ./install.sh create .env with fresh secrets, install Python 3.12 via uv, start PostgreSQL (pgvector), Redis, ClamAV and Ollama in Docker and download the fallback models. run.bat / ./run.sh start everything and open the browser. Add -Docker / --docker to run the app itself in a container.

Every device: the app listens on HTTP :8700 and HTTPS :8743. A local certificate authority is generated so phones, laptops and the Quest 3 can use the HTTPS address (needed for the microphone and location) — install /ca.crt once per device. Windows needs ports 8700/8743 allowed in the firewall (the installer asks once).

{{ icon('alert', 'w-5 h-5 text-amber-500') }}Known limits

  • Google Calendar entries are added through Google's template link and an .ics file (no OAuth), and Google Meet links must be created by you.
  • Immersive mode decorates the 2D browser window; it is not a full WebXR room.
  • Without a YouTube or TMDB key, video lookup uses YouTube's public search page and streaming availability falls back to search links.
  • The local 12B model answers most things; truly expert work escalates only when an online provider key is configured.
